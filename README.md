# Koushik — Premium Digital Portfolio

A dark-themed, animation-forward portfolio site built with React, TypeScript, Vite, and Tailwind CSS.

## Run locally

**Prerequisites:** Node.js

1. Install dependencies:
   `npm install`
2. Run the dev server:
   `npm run dev`
3. Build for production:
   `npm run build`

## Deployment

Deploys to Cloudflare Workers (see `wrangler.json`) via `npx wrangler deploy` after `npm run build`.
